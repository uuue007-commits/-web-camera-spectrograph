================================================================================
                        SPECTROMETER v6 — README
================================================================================

Приложение для спектральных измерений с веб-камеры или USB-камеры под
управлением Python + Tkinter. Позволяет в реальном времени получать спектр
источника света, калибровать шкалу длин волн по эталонным линиям, выделять
и зумировать области спектра, искать пики и экспортировать результаты
в PNG/CSV.

1. ВОЗМОЖНОСТИ
================================================================================

  - Потоковый захват кадров с камеры в отдельном потоке (не блокирует UI).
  - Выделение ROI — горизонтальной полосы, с которой считывается спектр.
  - Калибровка по длинам волн — по 2 и более эталонным линиям
    (CFL, Hg, H, He, Ne, Na), с расчётом RMSE и R².
  - Лупа для точного позиционирования пиков при калибровке (масштаб ±25 px).
  - Поиск пиков через scipy.signal.find_peaks (с fallback на ручной алгоритм).
  - Сглаживание фильтром Савицкого–Голея или скользящим средним.
  - Hold Peaks — удержание максимальных значений во времени.
  - Тёмный спектр с вычитанием из сигнала.
  - Коррекция чувствительности — загрузка коэффициентов (например, из файлов
    Theremino) и умножение сигнала на интерполированную кривую.
  - Log-шкала для визуализации малых пиков.
  - Выбор канала: яркость, среднее RGB, R, G, B.
  - Переворот камеры/спектра (flip).
  - Выделение области спектра мышью с последующим зумом и ограничением
    поиска пиков.
  - Экспорт в PNG (график) и CSV (пиксель / нм / интенсивность / канал).

================================================================================
2. ТРЕБОВАНИЯ
================================================================================

  - Python 3.9+
  - Зависимости:
        opencv-python (или opencv-python-headless + отдельный GUI)
        numpy
        matplotlib
        scipy (опционально, но рекомендуется — иначе поиск пиков
               и сглаживание работают медленнее)
        tkinter — обычно входит в стандартную поставку Python на Windows;
                  на Linux ставится пакетом python3-tk

Установка зависимостей:

    pip install opencv-python numpy matplotlib scipy

================================================================================
3. УСТАНОВКА
================================================================================

  1. Скопируйте spectrometer_v6_optimized.py в удобную папку.
  2. (Опционально) положите рядом файл калибровки caldata_v6.txt —
     приложение подхватит его автоматически.
  3. Запустите:

        python spectrometer_v6_optimized.py

При старте приложение автоматически пытается открыть камеру с индексом 0.

================================================================================
4. БЫСТРЫЙ СТАРТ
================================================================================

  1. Запустите приложение. Камера откроется автоматически; в окне появится
     поток с камеры и график.
  2. Настройте ROI — сдвиньте полосу так, чтобы она пересекала спектральную
     линию (дифракционный спектр на экране/щели).
  3. Отрегулируйте экспозицию и усиление, чтобы пик не был пересвечен
     (не «упирался» в 255).
  4. Выполните калибровку (кнопка «Калибровка») по эталонной лампе,
     например CFL.
  5. Сохраните калибровку (кнопка «Применить» — она сама пишет
     в caldata_v6.txt и JSON).
  6. Измеряйте: наводите камеру на образец, читайте длины волн пиков
     на графике.
  7. Экспортируйте результат кнопками «CSV» или «Снимок PNG».

================================================================================
5. ИНТЕРФЕЙС
================================================================================

--------------------------------------------------------------------------------
5.1. График спектра
--------------------------------------------------------------------------------

  - По оси X — длина волны (нм), по умолчанию диапазон 250–780 нм.
  - По оси Y — интенсивность (или log10 интенсивности).
  - Цветная заливка под кривой — восстановленный визуальный цвет
    соответствующей длины волны.
  - Красные ромбики — найденные пики; рядом подпись
    "λ (интенсивность)".
  - Прямоугольник выделения (жёлтый) появляется при работе в режиме
    выделения.

--------------------------------------------------------------------------------
5.2. Панель управления
--------------------------------------------------------------------------------

Верхний ряд кнопок:

    Кнопка                  Назначение
    ----------------------  ----------------------------------------------
    Стоп / Пуск             Остановить или запустить захват с камеры
    Пауза / Продолжить      Заморозить/разморозить график
                            (камера продолжает работать)
    Настройки камеры        Диалог тонкой настройки параметров
                            (экспозиция, гейн, ББ и др.)
    Калибровка              Открыть окно калибровки по эталонным линиям
    Коррекция…              Загрузить файл коррекции чувствительности
    Тёмный спектр           Сохранить текущий спектр как «тёмный»
                            и включить его вычитание
    Снимок PNG              Сохранить текущий график в PNG
    CSV                     Экспортировать данные спектра в CSV
    Выход                   Корректно закрыть приложение

Чекбоксы:

    - Flip камеры        — отразить видео по горизонтали.
    - Flip спектра       — отразить график по оси X.
    - Hold Peaks         — накапливать максимумы по времени.
    - Dark subtraction   — вычитать сохранённый тёмный спектр.
    - Коррекция вкл      — применять загруженную коррекцию.
    - Log шкала          — логарифмическая ось Y.
    - Канал              — что именно интегрируется по ROI:
                           Яркость (L = 0.299R + 0.587G + 0.114B),
                           Среднее RGB, отдельные R, G, B.

Слайдеры:

    - Экспозиция          — cv2.CAP_PROP_EXPOSURE (значения зависят
                            от драйвера, обычно отрицательные для ручного).
    - Усиление            — cv2.CAP_PROP_GAIN.
    - Сглаживание         — размер окна фильтра (нечётное).
    - Порог пиков, %      — относительный порог для find_peaks.
    - Мин. дистанция      — минимальное расстояние между пиками
                            в пикселях.

ROI:

    - Центр ROI, %        — положение полосы по вертикали.
    - Толщина, px         — высота полосы.
    - Индекс камеры       — номер устройства (/dev/video0, 0, 1 и т.п.).

--------------------------------------------------------------------------------
5.3. Выделение области спектра
--------------------------------------------------------------------------------

Кнопки в нижней строке:

    Кнопка                          Действие
    ------------------------------  -------------------------------------
    Режим выделения                 Включить/выключить режим
                                    выделения мышью
    Приблизить                      Зум на выделенную область
    Сбросить вид                    Вернуть полный диапазон (250–780 нм)
    Снять выделение                 Убрать прямоугольник и ограничение
                                    пиков
    Пики только в выделении         Ограничить поиск пиков выделенной
                                    областью
    Область: …                      Метка с текущим диапазоном в нм

Как пользоваться:

    1. Нажмите «Режим выделения» — курсор графика станет перекрестием.
    2. Зажмите ЛКМ и протяните по нужному диапазону длин волн.
    3. Отпустите — появится жёлтый прямоугольник, в метке появится
       диапазон.
    4. Нажмите «Приблизить» — график приблизится к выделению.
    5. Включите «Пики только в выделении», чтобы отфильтровать подписи
       пиков.
    6. «Снять выделение» и «Сбросить вид» возвращают исходный вид.

================================================================================
6. КАЛИБРОВКА
================================================================================

Кнопка «Калибровка» открывает отдельное окно.

Порядок работы:

  1. Выберите лампу из списка (CFL / ЛДС, Ртуть, Водород, Гелий, Неон,
     Натрий, Свободный режим).
        В режиме с эталоном приложение автоматически подставляет длины
        волн слева направо.

  2. Кликните по пику на графике — он будет привязан к первой
     неиспользованной линии.

  3. Для точного попадания:
        - двигайте маркер стрелками ← → (±1 px),
          Shift — ±10 px, Ctrl — ±0.1 px;
        - нажмите «К пику» — маркер прыгнет на локальный максимум;
        - используйте лупу под графиком — она показывает окрестность ±25 px.

  4. Таблица точек — можно удалять отдельные строки или очистить все.

  5. «Применить» — рассчитывается полином (до 3-й степени) методом
     наименьших квадратов, выводятся RMSE и R². Точки сохраняются
     в caldata_v6.txt и ~/.spectrometer_v6_calibration.json.

  6. «Сброс калибровки» — восстановить заводские точки:
        (0, 380 нм), (середина, 545 нм), (последний px, 750 нм).

Формула:

    Строится полином степени min(N−1, 3):

        λ(p) = c0 + c1·p + c2·p² + c3·p³

    где p — пиксель, λ — длина волны в нм. Для ≥4 точек используется
    кубическая зависимость, что типично для дифракционной решётки.

================================================================================
7. НАСТРОЙКИ КАМЕРЫ
================================================================================

Окно «Настройки камеры» открывает прямой доступ к параметрам OpenCV:

    Параметр            Свойство OpenCV
    ------------------  ---------------------------------
    Экспозиция          CAP_PROP_EXPOSURE
    Усиление            CAP_PROP_GAIN
    Яркость             CAP_PROP_BRIGHTNESS
    Контраст            CAP_PROP_CONTRAST
    Насыщенность        CAP_PROP_SATURATION
    Гамма               CAP_PROP_GAMMA
    Резкость            CAP_PROP_SHARPNESS
    Баланс белого       CAP_PROP_WB_TEMPERATURE

Также доступны переключатели:

  - Автоэкспозиция — варианты 0.25 (ручная V4L2), 0.75 (авто V4L2),
    0 (ручная), 1 (авто).
  - Автобаланс белого — вкл/выкл/не изменять.

Пустое поле = не изменять. Значения зависят от драйвера камеры
(обычно для ручной экспозиции используют отрицательные числа,
например −6 — 1/64 с).

================================================================================
8. КОРРЕКЦИЯ ЧУВСТВИТЕЛЬНОСТИ
================================================================================

Кнопка «Коррекция…» загружает текстовый файл с парами
«длина волны → коэффициент». Поддерживаются файлы в стиле Theremino —
любые строки с двумя числами через пробел или запятую; строки,
начинающиеся с "-", игнорируются.

Формат:

    380  0.25
    400  0.30
    450  0.55
    ...
    750  1.10

После загрузки в правом нижнем углу появится метка
"Коррекция: <имя файла> (N точек)", а чекбокс «Коррекция вкл» включится
автоматически. Значения коэффициента интерполируются линейно к текущей
шкале длин волн и умножаются на сигнал.

9. СОХРАНЕНИЕ ДАННЫХ
================================================================================

PNG
---
Кнопка «Снимок PNG» сохраняет текущий matplotlib-график в файл
spectrum_YYYYMMDD_HHMMSS.png в рабочей директории.

CSV
---
Кнопка «CSV» сохраняет таблицу с колонками:

    pixel | wavelength_nm | intensity_counts | channel
    ------+---------------+------------------+----------
      0   | 380.12345678  |    12.345678     | Яркость
      1   | 380.34567890  |    13.567890     | Яркость
      ... | ...           |    ...           | ...

Разделитель — ";", кодировка — utf-8-sig (совместимо с Excel).

10. ФАЙЛЫ КОНФИГУРАЦИИ
================================================================================

    Файл                                  Назначение
    ------------------------------------  --------------------------------
    caldata_v6.txt                        Калибровка в простом формате
                                          (две строки CSV)
    ~/.spectrometer_v6_calibration.json   Калибровка в JSON, включая
                                          ширину кадра

При запуске приложение сначала пробует прочитать caldata_v6.txt
из рабочей папки, затем JSON из домашней директории. Если ни того,
ни другого нет — используются встроенные значения по умолчанию
(0 → 380 нм, середина → 545 нм, конец → 750 нм), которые автоматически
масштабируются под ширину кадра.

================================================================================
11. АРХИТЕКТУРА
================================================================================

    spectrometer_v6_optimized.py
    |
    +-- утилиты
    |     wavelengths_to_rgb_batch()   — длина волны → RGB
    |     find_peaks()                 — поиск пиков (scipy/fallback)
    |     smooth_data()                — сглаживание (Savitzky-Golay/boxcar)
    |     darken()                     — затемнение hex-цвета
    |     load_theremino_corrections() — парсер файла коррекции
    |
    +-- Camera                         — потоковый захват в отдельном потоке
    |     run()                        — цикл чтения кадров и обработки команд
    |     snapshot()                   — копия последнего кадра + метрики
    |     set_property() / get_properties() — очередь команд/запросов
    |     close()                      — корректная остановка
    |
    +-- SpectrometerApp                — Tkinter-приложение
          _build_ui()                  — построение интерфейса
          _update_loop()               — 20 Гц цикл обновления
          _process_spectrum()          — сигнал → интенсивность
          _draw_graph()                — отрисовка графика
          _draw_preview()              — превью камеры
          open_calibration()           — окно калибровки
          camera_settings()            — окно настроек камеры
          выделение области:
             _toggle_select_mode / _zoom_to_selection /
             _reset_zoom / _clear_selection / _on_graph_*

Потокобезопасность.
    Класс Camera вынесен в daemon-поток. Общение с ним идёт через две
    очереди: commands (set_property) и queries/responses
    (get_properties). Кадры копируются под lock, чтобы избежать гонок.

Производительность.
    Тяжёлые операции (обработка спектра, отрисовка) выполняются
    в UI-потоке, но с частотой ~10 Гц (график) и ~20 Гц (превью камеры) —
    частота кадров камеры при этом не ограничивается.

================================================================================
12. ИЗВЕСТНЫЕ ОГРАНИЧЕНИЯ
================================================================================

  - Один активный источник — камера с индексом из поля «Индекс камеры».
  - Калибровка глобальная — на ширину кадра; при смене разрешения точки
    пересчитываются по маске.
  - Не сохраняются в JSON: параметры экспозиции/усиления, ROI, состояние
    чекбоксов. При следующем запуске их нужно задавать заново
    (кроме калибровки).
  - Flip камеры влияет только на превью; на спектр влияет Flip спектра.
  - Отрицательные длины волн после полинома не отсекаются — при
    неправильной калибровке шкала может уйти в минус.
  - Коррекция применяется после вычитания тёмного и до сглаживания.
  - Hold Peaks + сглаживание применяются одновременно;
    порядок: hold → dark → irradiance → smooth.
